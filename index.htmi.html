4주 입문/중급

파이썬 & SQL 데이터 분석 마스터

  • 1주차: 파이썬 데이터 다루기 기초 Pandas, Numpy를 활용한 데이터 정제 및 가공 핵심
  • 2주차: SQL 데이터베이스 추출 및 조회 실무에서 쓰이는 복합 쿼리문 및 조인(Join) 완벽 이해
  • 3주차: 대시보드 시각화 프로젝트 지표 정의 및 대시보드를 통한 비즈니스 인사이트 도출
  • 4주차: 최종 파이널 프로젝트 & 1:1 피드백 실제 데이터를 활용한 포트폴리오 제작 완료
4주 실전

풀스택 웹 서비스 제작 코스

  • 1주차: 모던 HTML/CSS & Tailwind 반응형 웹 UI 구현 및 레이아웃 설계
  • 2주차: JavaScript 핵심 인터랙션 동적 데이터 처리 및 API 연동 기초
  • 3주차: 서버 연결 및 데이터베이스 백엔드 API 호출 및 데이터 저장 처리
  • 4주차: 서비스 배포 및 론칭 나만의 웹 사이트 라이브 배포 및 멘토링
4주 문서/기획

서비스 기획 & PM 역량 강화

  • 1주차: 서비스 문제 정의 및 PRD 작성 요구사항 정의서와 서비스 기획서의 표준
  • 2주차: 와이어프레임 & 프로토타이핑 Figma를 활용한 화면 설계 및 사용자 경험 설계
  • 3주차: 지표 설계 및 A/B 테스트 Funnel 분석 및 성과 측정을 위한 지표 설정
  • 4주차: 역기획서 포트폴리오 완성 실제 서비스 분석을 바탕으로 한 역기획서 제출
